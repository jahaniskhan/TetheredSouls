## Overall Goal
TetheredSouls is an interactive iOS game that combines block-placement mechanics with a responsive cat character. The goal is to create an engaging user experience where:

1. Users can drag and place blocks in a grid
2. A responsive cat character reacts to user interactions
3. The cat provides visual feedback by looking at where the user is interacting
4. During block dragging, the cat's eyes specifically look downward to follow the grid
5. Different moods affect the cat's appearance (curious, excited, loving)
6. Direct touches on the cat generate heart animations and mood changes

The code is structured to maintain separation of concerns while ensuring smooth state coordination between components.
