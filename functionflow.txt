# Block Dragging System Diagnosis

## Core Architecture Flaws
1. **Dual Coordinate Systems**:
   - `BlockSelectionView` uses global screen coordinates
   - `DraggableBlock` uses `.gameArea` coordinates
   - `GridView` calculates positions in local grid space
   - *Result*: Dragged blocks spawn at screen center instead of touch point

2. **Static vs Dynamic Sizing**:
   - Inventory blocks (BlockPreview): 60x60 fixed size
   - Grid cells: Dynamic calculation (`(screenWidth - padding)/10`)
   - Dragged blocks: Hardcoded 60pt size
   - *Result*: Size mismatch between inventory/grid/dragged views

3. **State Propagation Chain**:
```mermaid
graph TD
    A[BlockSelectionView] -->|sets| B(selectedBlock)
    B --> C[ContentView]
    C -->|creates| D[DraggableBlock]
    D -->|updates| E[GridProjectionCoordinator]
    E -->|notifies| F[GridView]
```
- Missing feedback loop from GridView to BlockSelectionView
- No cleanup mechanism after failed placements

## Technical Debt Culprits
1. **Hardcoded Grid Parameters** (DraggableBlock.swift):
```swift
let gridSize = CGSize(width: 30, height: 30) // Should match GridView's cellSize
let gridOrigin = CGPoint(x: 20, y: 100) // Should be actual grid position
```

2. **Incomplete State Reset** (ContentView.swift):
```swift
// Missing cleanup of blockPosition and projectedCells
.onChange(of: isDragging) { newValue in
    if !newValue {
        selectedBlock = nil
        // Need to reset blockPosition and projectedCells here
    }
}
```

3. **Gesture Conflict** (BlockSelectionView.swift):
```swift
.gesture(
    DragGesture(minimumDistance: 2, coordinateSpace: .global)
        .onChanged { /*...*/ } // Competes with DraggableBlock's gesture
)
```

## Required Fixes

### 1. Coordinate Space Unification
```swift
// In GridView:
.background(
    GeometryReader { geo in
        Color.clear
            .preference(key: GridFrameKey.self, 
                       value: geo.frame(in: .global))
    }
)
// Pass this frame to DraggableBlock
```

### 2. Dynamic Block Sizing
```swift
// Modify DraggableBlock initialization:
init(..., gridCellSize: CGFloat) {
    self.cellSize = gridCellSize
    // Use for block rendering and projection
}
```

### 3. State Management Overhaul
```swift
// New cleanup protocol:
protocol DragStateResettable {
    func resetDragStates()
}

// Implement in ContentView/DraggableBlock
func resetDragStates() {
    selectedBlock = nil
    blockPosition = nil
    isDragging = false
    GridProjectionCoordinator.shared.projectedCells = []
}
```

## Expected Outcome
- Blocks spawn at touch location with proper size
- Single-finger drags work intuitively
- Projections align perfectly with grid cells
- State clears completely after placement attempts

## Preservation Strategy
- Maintain existing gesture recognizers
- Keep projection calculation logic
- Reuse current state bindings
- Avoid modifying heart animation system
